# 🌐 Web Application Testing Project

## 📌 Project Overview

This project demonstrates **manual testing and API testing** of a Task
Management System developed using **Node.js, Express, and MongoDB**.

The system includes authentication functionality and full CRUD
operations for task management.

------------------------------------------------------------------------

## 🚀 Features Implemented

-   🔐 **User Registration**
-   🔑 **User Login**
-   ➕ **Add Task**
-   📋 **View Tasks**
-   ✏ **Update Task**
-   🗑 **Delete Task**

------------------------------------------------------------------------

## 🧪 Testing Coverage

The following testing types were performed:

-   ✅ Functional Testing\
-   ✅ Negative Testing\
-   ✅ Validation Testing\
-   ✅ API Testing using Postman\
-   ✅ Database Verification using MongoDB Compass
